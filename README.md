# Dandy World — Математический тренажёр

Игра для подготовки ко 2-му классу. Персонажи из Dandy World.

## Как запустить локально
Просто открой index.html в браузере.

## Как задеплоить на GitHub Pages
1. Зарегистрируйся на github.com
2. Создай новый репозиторий (New repository), назови его: dandy-world
3. Загрузи все файлы проекта в репозиторий
4. Перейди: Settings → Pages → Source → Deploy from a branch → main → / (root) → Save
5. Через 1-2 минуты игра будет доступна по адресу:
   https://ТВОЁ_ИМЯ_НА_ГИТХАБ.github.io/dandy-world/

После этого игра работает на любом устройстве, в России, без установки.
